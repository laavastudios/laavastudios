## `principles`

| Principle | Standard |
|---|---|
| **Build for reality** | Production behavior matters more than demo behavior. |
| **Own the stack** | Prefer transparent architecture and controllable infrastructure. |
| **Automate repetition** | Repeated manual work should become a system. |
| **Design is engineering** | A technically strong product should also feel deliberate. |
| **Ship** | Small working releases beat unfinished perfection. |
| **Learn by building** | Theory becomes valuable when it survives implementation. |
